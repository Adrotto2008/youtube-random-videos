🎲 YouTube Video Casuale — Guida all'installazione

Questa estensione aggiunge un pulsante "Casuale" nella tab Video di un canale YouTube: mostra tutti i video del canale in ordine mescolato, non solo i più recenti o i più popolari.

1. Installa l'estensione

  1. Estrai/scarica la cartella con tutti i file (manifest.json, content.js, options.html, options.js) in un posto fisso del tuo computer — non spostarla né cancellarla dopo, o l'estensione smette di funzionare.
  2. Apri il browser (Chrome, Opera GX, Edge... funziona su tutti quelli basati su Chromium) e vai su chrome://extensions (su Opera GX: opera://extensions).
  3. Attiva la "Modalità sviluppatore" (interruttore in alto a destra).
  4. Clicca "Carica estensione non pacchettizzata" e seleziona la cartella del punto 1.

2. Procurati la tua chiave API gratuita

⚠️ Ogni persona deve usare la propria chiave, gratuita. Non è inclusa nel pacchetto per motivi di sicurezza e di quota giornaliera.
  1. Vai su console.cloud.google.com e accedi con un account Google.
  2. In alto, menu progetti → "Nuovo progetto". Dagli un nome a caso e crealo.
  3. Menu laterale → "API e servizi" → "Libreria", cerca "YouTube Data API v3" e clicca "Abilita".
  4. "API e servizi" → "Credenziali" → "Crea credenziali" → "Chiave API". Ti genera una stringa tipo AIzaSy...: quella è la tua chiave.
  5. (Consigliato) Clicca sulla chiave appena creata → sotto "Restrizioni API" seleziona solo "YouTube Data API v3", così è utilizzabile solo per questo scopo.

3. Inserisci la chiave nell'estensione

  1. Vai su chrome://extensions (o opera://extensions).
  2. Trova "YouTube Video Casuale" → clicca "Dettagli".
  3. Clicca "Opzioni estensione".
  4. Incolla la tua chiave API nel campo e premi "Salva".

4. Usala

  1. Vai sul canale YouTube che ti interessa.
  2. Apri la tab "Video".
  3. Vicino a "Più recenti / Popolari / Meno recenti" comparirà il pulsante "Casuale". Cliccalo.
  4. La prima volta su un canale ci vorranno alcuni secondi (scarica l'elenco completo dei video). Le volte successive, entro 24 ore, sarà istantaneo.

Cose da sapere

  • La chiave API gratuita ha un limite di 10.000 richieste al giorno: più che sufficiente per uso personale, anche intenso.
  • Se non hai ancora inserito una chiave, il pulsante "Casuale" te lo ricorderà quando lo clicchi.
  • Funziona solo sui video pubblici del canale (non su contenuti riservati agli iscritti).
